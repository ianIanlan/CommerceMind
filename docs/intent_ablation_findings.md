# 意图识别消融实验结论

## 实验设置

- 数据：30 条电商客服合成问句，覆盖订单、物流、支付、退款、售后、技术和人工升级。
- 指标：Accuracy、Macro-F1、平均延迟、逐样本错误。
- 模型：`deepseek-flash`，Responses SSE 接口。
- 原始报告由 `scripts/run_ablation.py` 生成到本地 `outputs/` 目录；该目录不提交到仓库。

## 当前结果

| 方案 | Accuracy | Macro-F1 | 平均延迟 |
|---|---:|---:|---:|
| 关键词单路 | 0.9000 | 0.8417 | P50 0.080 / P95 0.137 ms |
| Embedding 单路 | 0.5000 | 0.4500 | P50 3.804 / P95 4.253 ms |
| LLM 单路 | 0.8667 | 0.8000 | P50 2082 / P95 5829 ms |
| Embedding + 关键词 | 0.6000 | 0.5621 | P50 3.890 / P95 4.325 ms |
| LLM + 关键词 | 0.9333 | 0.9067 | P50 2082 / P95 5829 ms |
| 朴素三路加权 | 0.9333 | 0.9067 | P50 2086 / P95 5833 ms |
| 生产融合策略 | 0.9667 | 0.9719 | P50 2086 / P95 5833 ms |

## 可以得出的结论

1. 关键词路径在当前窄领域数据上便宜且强，适合高信息量短语和 LLM 降级。
2. 当前字符 n-gram Embedding 单路效果较差，简单加入融合不保证提升。
3. LLM 提升了隐式表达识别，但本次平均延迟约 2.6 秒、P95 约 5.8 秒，重试后仍有 6.67% 失败率。
4. LLM + 关键词比任一单路更稳定；生产融合再利用细粒度优先和失败降级修正边界样本。
5. Responses 网关需要一次受控重试来缓解偶发空输出，但重试只应针对可重试解析失败。

## 不能得出的结论

- 不能声称线上意图准确率为 100%。数据量小，且规则和数据集来自相同业务定义。
- 不能据此声称当前 Embedding 永远无效；它只是说明字符 n-gram 实现和模板需要优化或替换。
- 不能只看 Accuracy。后续应加入真实改写、错别字、对抗表达、类别不平衡和跨轮语境。

## 下一轮实验

1. 扩充到至少 200 条，划分开发集和盲测集；当前生产融合 96.67% 的 95% Wilson 区间为 83.33%-99.41%。
2. 实时 LLM 实验重复 3 次，报告均值、标准差和失败率。
3. 对比本地字符向量与真正的语义 Embedding 模型。
4. 增加 RAG：无检索、纯向量、向量 + 元数据过滤、向量 + 重排。
5. 增加编排：单 Agent、固定多 Agent、条件多 Agent。

## 鲁棒性追加实验与决策

追加 20 条口语、省略、否定和隐式表达后，关键词单路为 5%，字符 n-gram Embedding 为
15%，LLM 单路为 90%。加入当前 Embedding 后仍为 90%，没有准确率增益；LLM 重试后失败率
为 10%，P95 延迟约 8.7 秒。

因此生产配置默认设置 `INTENT_EMBEDDING_ENABLED=false`，采用 LLM + 高信息量关键词规则。
字符向量实现仅保留为实验对照，不再作为线上失败降级路径。只有更换真正语义 Embedding、
并在独立盲测集证明有稳定增益后才重新启用。
