# LLM + BGE + 关键词融合冻结实验 v1

## 实验设置

- 数据集：`intent_holdout_v1.jsonl`，20 条冻结合成样本。
- SHA-256：`2c68252a0e05c29e2e18e32399528b5a681701f3b1da12fe486e87efb6d88801`。
- LLM：项目 `.env` 配置的 `deepseek-flash`，Responses API。
- Embedding：FastEmbed `BAAI/bge-small-zh-v1.5`，本地 ONNX CPU。
- 关键词：冻结前已有的确定性规则。
- 原始模型输出保留在本地忽略目录，不提交密钥、提示词响应或供应商元数据。

## 结果

| 方案 | Accuracy (Wilson 95% CI) | Macro-F1 | P50 | P95 | 错误数 |
|---|---:|---:|---:|---:|---:|
| 关键词 | 20.00% [8.07%, 41.60%] | 15.59% | 0.08 ms | 0.10 ms | 16 |
| BGE 中文 Embedding | 30.00% [14.55%, 51.90%] | 24.24% | 11.85 ms | 48.55 ms | 14 |
| LLM 单路 | 90.00% [69.90%, 97.21%] | 86.67% | 2428.06 ms | 6613.06 ms | 2 |
| LLM + 关键词 | 90.00% [69.90%, 97.21%] | 86.67% | 2428.15 ms | 6613.12 ms | 2 |

| 生产融合规则 | 95.00% [76.39%, 99.11%] | 93.33% | 2440.00 ms | 6622.56 ms | 1 |

单路指标：

- LLM 平均延迟 2892.52 ms，最大 7031.97 ms，失败率 5%。
- BGE warm average 13.01 ms，本轮冷启动 387.06 ms，失败率 0%。
- 关键词平均延迟 0.08 ms，失败率 0%。

## 错误分析

LLM 单路错误两条：

1. “收到以后不太喜欢，想把货退回去拿回钱”被判为 `return_exchange`，期望为 `refund`。这是相邻意图边界错误，LLM 和 BGE 都给出了同一错误，因此融合无法纠正。
2. “下午好，请问现在有人在线吗”发生 LLM 非 JSON/空结果失败；融合通过其他本地证据恢复为正确结果。

生产融合只剩第一条错误。

## 可以与不可以得出的结论

可以得出：

- 在这组冻结样本中，LLM 是主要准确率来源。
- 本地路径能在一次 LLM 格式失败时提供可用降级。
- 三路融合比 LLM 单路多正确 1 条，同时增加约 12 ms 热路径开销。

不能得出：

- 20 条样本不足以证明 90% 与 95% 存在统计显著差异。
- 不能把 Wilson 区间解释为模型在真实生产流量上的保证。
- 不能声称 BGE 单路已经适合生产意图路由。
- 当前网关未返回可审计的 token usage，因此尚未报告真实单次成本。

下一轮应冻结规模更大的 v2，重点增加相邻意图边界、LLM 非 JSON、超时和多轮上下文样本，并记录供应商 token usage。
