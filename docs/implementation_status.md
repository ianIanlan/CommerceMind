## 当前已知边界

1. `AUTH_MODE=demo` 只用于本地演示；生产必须设置 `signed_token` 和高强度 `AUTH_SECRET`，或接入企业身份网关。
2. Docker 全栈已完成烟雾验收；第三方 LLM 网关仍可能出现 429/503，需要按部署方配额配置重试、限流与降级。
3. 当前退款执行只创建模拟退款申请，不接入真实支付渠道。
4. 各消融数据集规模仍较小，实验结果不能外推为线上准确率。
5. Docker 默认使用稳定的字符 n-gram 离线向量，避免首次启动下载模型；其语义能力弱于训练型 Embedding，生产环境应替换并做在线消融。
